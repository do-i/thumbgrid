# Video controls part 2 — clip range editor (replaces `A-B`)

Model tiers: **Haiku 5.5** = mechanical, pinned edits · **Sonnet 5.5** = standard coding · **Opus 5.5** = UX/state judgment, visual iteration.

## Agreed behavior

| Topic | Decision |
|---|---|
| Button | Bracket-range icon `[ ]` replaces the `A-B` text button; a second icon variant shows edit mode |
| Edit mode | Click → two handles on the seek bar. Start = current position, end = start + 10 s (clamped to end of file). Range shaded, the rest dimmed |
| While dragging a handle | Video seeks to the handle (live preview frame) + time tooltip |
| Fine-tune | Prev/next-frame buttons and keys move the last-touched handle while editing |
| Commit / cancel | Click button again = commit · Esc = cancel (old clip, if any, kept) |
| After commit | Handles stay visible (slim, not draggable) so the active clip is always shown |
| Clear clip | Right-click the clip button, or `clearClip` shortcut |
| Seek with clip active | Clamped into [start, end] — **tentative**, kept in one function so it's easy to switch after you try it |
| Play | Inside [start, end) → resume · at/after end or outside → restart at start |
| Loop button (new) | Clip active: loop on = repeat clip, off = pause at end · No clip: loops whole file (replaces today's always-on `loop-file`) |
| File change | Clip cleared |
| Keyboard marking | `[` = set start here, `]` = set end here (works without edit mode; auto-creates the clip) |

### 1 · Millisecond positions (video only)
- `mpvwidget.cpp` (gl + nogl): emit `time-pos`/`duration` as ms; `seek` takes ms (`"absolute"` with `pos/1000.0`).
- `VideoPlayer` interface + `VideoControls`: video units = ms, labels still `mm:ss`; **animations stay in frames**.
- Stale installed plugin under `/usr/lib` would misread the units → add a plugin interface version symbol and refuse a mismatched plugin.

### 2 · `VideoSlider` overlay
- `setClipRange(start, end)`, `setClipEditable(bool)`; signals `clipStartMoved(int)` / `clipEndMoved(int)` / `clipHandleTouched(which)`.
- Handle hit area larger than the drawn handle (thin bar); a press on a handle starts a handle drag, not a seek.
- Colors from the theme (accent for range, dimmed track outside).

### 3 · Clip state machine
- States `NONE → EDITING → ACTIVE`; replaces `LoopABState` / `loopABButton`.
- Preview seeks during drag throttled (about one every 50 ms) so mpv isn't flooded.

### 4 · Playback rules
- Active clip → mpv `ab-loop-a/b` when loop on; when off, watch position and pause at end.
- Loop button drives `loop-file` when no clip; slideshow still forces loop off (`core.cpp` start/stopSlideshow).
