## 3. Code security review

| # | Finding | Status |
|---|---|---|
| S1 | Show-in-folder and set-wallpaper (Linux/FreeBSD) built `"dolphin --select " + path` and re-split it on spaces and quotes. Paths with spaces broke, and a crafted filename could inject extra arguments. GNOME was also given a plain path where it expects a URI. | Fixed: argument lists, `file://` URI |
| S2 | The video-thumbnail `mpv` subprocess took the file path with no `--` separator and left ytdl and reference-following on. A `.mov` reference or disguised playlist could make it fetch remote URLs (privacy leak) just from browsing a folder. | Fixed: `--`, `--ytdl=no`, `--access-references=no` (verified with a file named `-dash.mp4`) |
| S3 | libmpv player loaded built-in Lua scripts and the ytdl hook | Fixed: `ytdl=no`, `load-scripts=no` |
| S4 | Player plugin search fell back to `.` (the current directory) if `makeAbsolute()` failed, a library-hijack path | Fixed |
| S5 | User scripts run configured commands via `QProcess` with no shell, and `%file%` substitution is per-argument | OK as designed |
| S6 | Rename path traversal, symlink-safe delete, copy/move containment, private temp dirs, HTML-escaped names in rich text | Already guarded; verified |
| S7 | clang-tidy (analyzer, bugprone, cert, performance) on all non-test sources | 0 analyzer findings; the real bugs it found are fixed above |
