# 2026-10-06-001 — Resize from the grid context menu

Add **Resize…** to the folder-grid right-click menu. Output is always a **new
copy** next to the original (decided: option A). Originals are never touched.

**Model legend:** Haiku 4.5 = mechanical, pinned edits · Sonnet 5.5 = standard
coding against an existing pattern · Opus 5.5 = design judgment / tricky edge
cases.

## Current state (verified in code)

| Fact | Where |
|---|---|

| Grid menu has no Resize | `src/gui/folderview/gridcontextmenu.cpp` |

## Behavior spec

| Aspect | Rule |
|---|---|
| Menu item | "Resize…" directly under "Convert to…"; enabled when selection is non-empty and `allConvertible` (same gate as Convert) |
| Folders in selection | Expanded to directly contained images, non-recursive (same as Convert) |
| Skipped | Video, animated, non-static, and images already at/below target size when mode is *shrink only* |
| Dialog, 1 file | Existing dialog unchanged (exact W×H, keep aspect, presets) |
| Dialog, N files | Modes: **Percentage** · **Fit within W×H** (aspect always kept) · **Long edge = N px**. Exact W×H hidden — it would distort mixed shapes. Checkbox **Shrink only** (default on) |
| Filter | Dropdown: Bilinear (default) / Cubic / Cubic+sharpen when OpenCV is built; remembered in settings |
| Output name | `<base>_<W>x<H>.<ext>` next to the original; on clash append `-1`, `-2`… (never overwrite) |
| Output format | Same as source; formats `canEncodeToFormat` rejects are skipped |
| Metadata | Kept via `ImageStatic::save`; see Risk R1 |
| Result | Toast: "Resized N file(s)" / "Resized N, skipped M, failed K" |
| Viewer `R` / icon | Unchanged (in-place edit, user saves) |
| Folder-view `R` shortcut | Routes to the new copy flow instead of the broken unsaved edit |

## Items

### 1 — Grid menu entry + signal chain
*Model:* **Haiku 4.5** — pure mirror of the `convertFormatRequested` chain.
- `GridContextMenu`: `resizeItem`, signal `resizeRequested()`, gate in `setSelectionInfo`.
- Forward through `FolderGridView` → `FolderView` → `FolderViewProxy` → `MW` → `Core::showGridResizeDialog()`.

### 2 — Multi-file resize dialog
*Model:* **Sonnet 5.5** — UI work on an existing `.ui`; mind `notr="true"` on accessibleName (see QSS gotchas memory).
- Extend `ResizeDialog` with a `multi` constructor flag: mode radio (percent / fit / long edge), shrink-only, filter combo.
- Seed sizes with `QImageReader::size()` (no full decode); multi-mode shows "N images" instead of a size.
- Emit a `ResizeSpec { mode, value/QSize, shrinkOnly, filter }` struct.

### 3 — `FileOperationsController::resizeToCopies(paths, spec)`
*Model:* **Opus 5.5** — cache/edit-state interaction and naming collisions are the risky part.
- Expand folders, build jobs, compute per-image target from `spec`.
- Per job: get image → `setEditedImage(ImageLib::scaled(...))` → `save(dest)` → **discard edit** so the cached original (and the open viewer, if it is that file) is unchanged.
- Unique-name helper; summary toast. Keep synchronous for v1 (matches Convert); add a progress overlay only if > ~20 files feels slow (Decision 2).

### 4 — Fix folder-view `resize` action
*Model:* **Haiku 4.5** — one branch in `Core::showResizeDialog`.
- In `MODE_FOLDERVIEW` call the item-1 path; drop the `edit_template(false)` route there.

### 5 — Viewer menu tooltips
*Model:* **Haiku 4.5** — set tooltip text on the six transform `ActionButton`s, including shortcut text.

### 6 — Tests + i18n
*Model:* **Sonnet 5.5** — follow `test_grid_context_menu_gating.cpp`; HOME redirection per isolation memory.
- Gating: enabled for images, disabled for empty / video-only / non-convertible.
- Behavior: resize 2 fixture images (different aspect) in a temp dir by fit-within → two new files with expected sizes, originals byte-identical, clash gets `-1`.
- Metadata: jpg with Exif keeps it; orientation (R1).
- Run `lupdate` for new strings.

## Risks

| # | Risk | Mitigation |
|---|---|---|
| R1 | Exif keeps stale `PixelXDimension`/`Orientation`; if loader already applied orientation, copy could double-rotate | Item 3: after save, update dimension tags and reset Orientation to 1 when pixels are already oriented; test it |
| R2 | Discarding the edit could wipe a user's genuine unsaved edit on the same file | Skip (count as skipped) any file whose cached image `isEdited()` before we touch it |
| R3 | Large batch freezes UI (synchronous) | Acceptable for v1; Decision 2 |
